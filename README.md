# OrdenCompra-Java 🛒
Proyecto personal desarrollado en Java con enfoque en Programación Orientada a Objetos (POO).  
Este software simula la generación de órdenes de compra para un miniMarket.

## 💻 Características
- Construido en Java usando la IDE IntelliJ IDEA (Community Edition).
- Aplica conceptos clave de POO.
- Uso de enumeradores para productos.
- Relaciones entre clases: asociación, agregación y composición.
- Interfaz de consola simple para visualizar las órdenes generadas.
  
Ideal como práctica educativa de POO y manejo de estructuras en Java.
